# Direction contract: selected illustrations

Scope: curate and expose the existing illustration page in portfolio-v2. Preserve Archivo, the cream/orange palette, navigation and square project tiles. This is a narrow extension of an existing surface, not a new visual identity.

User outcome: a recruiter can see 11 selected works in five coherent series, enlarge them, read PL/EN descriptions and play the Soleo animation on demand. The blog remains an archive. Do not change unrelated CV or casino work.

Visual hierarchy: art leads the first viewport beside a short introduction. Use whole uncropped illustrations, two columns on desktop and one on mobile. Compact project icons use each project's own sign, with space around it, as explicitly requested by the user; do not use screenshots as tile fills.

Interaction and motion: native keyboard-accessible image dialog, arrow navigation and Escape close. No entrance animations or automatic mascot loop; animation has an explicit play/pause toggle in both page and dialog. Respect reduced motion for scrolling.

Verification: desktop at current user viewport, mobile 390 and 320; no document overflow, actual images load, project filter/link works, PL/EN updates labels, dialog and animation controls work.
