Uruchomienie strony CV lokalnie
==============================

1. Zaleznosci: Node.js (LTS) + npm
   https://nodejs.org/

2. W tym folderze (c:\cv):
   npm install
   npm run dev

3. Przegladarka:
   http://localhost:3000/         (CV)
   http://localhost:3000/cv.html  (alternatywnie)

Bez package.json: npx --yes serve . -p 3000
